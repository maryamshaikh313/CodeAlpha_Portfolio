# \# CodeAlpha\_Portfolio

# 

# A personal portfolio website built with HTML, CSS and JavaScript for the CodeAlpha Frontend Development internship (Task 3).

# 

# \*\*Live site:\*\* https://maryamshaikh313.github.io/CodeAlpha\_Portfolio/

# 

# \## About

# 

# This is the portfolio of Maryam Shaikh, a Computer Science undergraduate with a focus on Data Analytics, who is also building skills in AI automation and front-end development.

# 

# \## Sections

# 

# \- \*\*Hero:\*\* introduction with a link to projects

# \- \*\*About:\*\* background, focus areas and current internships

# \- \*\*Skills:\*\* grouped by Data \& Analytics, AI \& Automation, Front-End, Design and Tools

# \- \*\*Projects:\*\* selected work with links to GitHub, and a link to LinkedIn for more updates

# \- \*\*Contact:\*\* email, GitHub and LinkedIn

# 

# \## Features

# 

# \- Fully responsive layout for desktop, tablet and mobile

# \- Smooth scrolling between sections

# \- Scroll animations and hover effects

# \- Navigation link highlights the section you are viewing

# \- Copy-to-clipboard button for the email address

# \- Custom favicon

# \- Respects reduced-motion settings

# 

# \## Built with

# 

# HTML5, CSS3 (custom properties, grid, flexbox, animations) and vanilla JavaScript.

# 

# \## Project structure

# 

# ```

# CodeAlpha\_Portfolio/

# ├── index.html

# ├── style.css

# ├── script.js

# └── favicon.svg

# ```

# 

# \## Run locally

# 

# Download or clone the repository and open `index.html` in a browser. No installation is needed.

# 

# \## Deployment

# 

# Hosted on GitHub Pages from the `main` branch.
