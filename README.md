### CodeAlpha_Portfolio

A personal portfolio website built with HTML, CSS and JavaScript for the CodeAlpha Frontend Development internship (Task 3).

**Live site:** https://maryamshaikh313.github.io/CodeAlpha_Portfolio/

#### About

This is the portfolio of Maryam Shaikh, a Computer Science undergraduate with a focus on Data Analytics, who is also building skills in AI automation and front-end development.

#### Sections

- **Hero:** introduction with a link to projects
- **About:** background, focus areas and current internships
- **Skills:** Data & Analytics, AI & Automation, Front-End, Design and Tools
- **Projects:** selected work with GitHub links, and a LinkedIn link for more updates
- **Contact:** email, GitHub and LinkedIn

#### Features

- Responsive layout for desktop, tablet and mobile
- Smooth scrolling, scroll animations and hover effects
- Navigation highlights the section you are viewing
- Copy-to-clipboard button for the email address
- Custom favicon

#### Built with

HTML5, CSS3 and vanilla JavaScript (no libraries or frameworks).

#### Run locally

Download or clone the repository and open `index.html` in a browser. No installation is needed.
